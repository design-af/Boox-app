      How it flows

      1. Live: tap Start. The talk collects in Live; nothing is typed yet.
      2. Prep ▸: waits for the sentence to end, moves the segment to Prep. Recording carries on into the next segment. Claude only runs when you tap Check, Speakers or Summary.
      3. Prep: fix flagged words, read key points, then tap into your notes and Push.
      4. Library (here): every recording. Group them, and get key points for a whole group.
