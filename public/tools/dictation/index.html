The bubble floats over every app and your keyboard keeps working. Tap it for the panel, long-press to record, drag to move. The panel’s grip moves it; tap the grip to resize.

Set up once

1 MicrophoneTo hear the presenter.
2 Speech engineChecking…
3 Display over other appsLets the bubble and panel float on top.
4 Push into text fieldsAccessibility → Aside Transcribe → On. Without it, Push copies instead.
5 Claude API key (optional)In Settings. For the full Check and key points.

How it flows

  1. Live: tap Start. The talk collects in Live; nothing is typed yet.
  2. Prep ▸: waits for the sentence to end, moves the segment to Prep. Recording carries on into the next segment. Claude only runs when you tap Check, Speakers or Summary.
  3. Prep: fix flagged words, read key points, then tap into your notes and Push.
  4. Library (here): every recording. Group them, and get key points for a whole group.
